## Implementation

Project configuration now writes schema `1.1.0` while reading both `1.0.0` and `1.1.0`. Version `1.0.0` retains its exact Prompt 1 fields and rejects `acceptance`. Version `1.1.0` optionally accepts canonical comparison configuration, a paired baseline/change contract configuration, and an approved-reference configuration with optional explicit bindings. Paths are non-empty portable project-relative strings, reject absolute/drive/backslash/colon/NUL/dot/traversal forms, and are realpath-contained before use.

`current` remains rejected by human `capture`; the alias catalog accepts it only as system-managed state. `projectCheckService` resolves the explicit baseline or `defaultBaseline`, verifies catalog/artifact observation and request identity, captures one new immutable current observation, atomically updates `current`, calls the canonical comparison service once, and conditionally calls the existing contract and reference-fidelity services. It never invokes the CLI recursively, edits frontend source, infers bindings, or creates another evidence engine.

Canonical comparison artifacts persist under managed comparisons. Canonical contract evaluations persist under managed evaluations. Reference fidelity remains the existing in-memory result. There is no check artifact. The workflow precedence is BLOCKED, FAIL, PASS when every configured executable dimension passes, and REVIEW_REQUIRED when comparison succeeds without executable acceptance authority.

`checkResult` schema `1.0.0` projects project-relative artifact paths, canonical contract failures/unavailable/conflicts and unexpected changes, and canonical failed/unavailable reference requirements. Every problem collection is limited to 50; supporting evidence is limited to 10 per contract item; truncation is explicit. It embeds no image bytes or complete artifacts. Human output emphasizes `baseline`/`current`, concise failures/blockers, and `my-frontend-observer view`, without routine hashes or absolute paths. Exit codes are PASS 0, FAIL 1, REVIEW_REQUIRED 2, and BLOCKED 3.
