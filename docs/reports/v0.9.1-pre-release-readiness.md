## 8. Isolated hard-gate invariant

The prior readiness predicate was:

```text
registration?.active !== undefined
```

At failure time, active registration state was `null` and the current page
controller was `null`. The old predicate falsely passed because `null !==
undefined`. The corrected proof requires:

```text
registration.active !== null
navigator.serviceWorker.controller !== null
```

The experiment also proves shell precache, zero `/api/` cache entries, live
evidence visibility, actual server unavailability, offline shell rendering,
evidence becoming unavailable, and stale evidence remaining absent.
