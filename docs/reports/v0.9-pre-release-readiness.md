## 5. Workflow architecture

`.github/workflows/pre-release-readiness.yml` uses a Node 24 Ubuntu candidate
job. It runs `npm ci`, Chromium installation, typecheck, lint, unit tests,
real-Chromium browser tests, the security suite, build, documentation checks,
and `npm pack`. It uploads one candidate tarball and its SHA-256 file.

The Windows, Ubuntu, and macOS matrix jobs download that artifact, independently
verify its SHA-256, install Chromium, and run the packed observation, viewer,
and v0.9 annotation smokes. The workflow is triggered by `validation/**` and
retains workflow dispatch support.
