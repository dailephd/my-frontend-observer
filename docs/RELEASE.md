# Release

`v0.2.0` is published to npm as `my-frontend-observer`, validated on
Windows, Linux, and macOS as an installed packed-tarball consumer prior to
publication (covering both the legacy CSS-shorthand `--target` path and the
structured semantic `--targets-file` path). No project license has been
declared yet; that decision remains open for a later explicit task.

Observation schema version and package version remain separate: package
version is `0.2.0`; observation schema is `1.1.0` and does not change
automatically with the package version.
