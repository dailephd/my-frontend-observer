# Release

`v0.3.0` is published to npm as `my-frontend-observer`, validated on
Windows, Linux, and macOS as an installed packed-tarball consumer prior to
publication (covering the legacy CSS-shorthand `--target` path, the
structured semantic `--targets-file` path, and the bounded
`--scroll-scenario-file` `window-scroll-by`/`target-scroll-by` runtime
scroll scenario path). No project license has been declared yet; that
decision remains open for a later explicit task.

Observation schema version and package version remain separate: package
version is `0.3.0`; observation schema is `1.2.0` and does not change
automatically with the package version.

Prior releases: `v0.2.0` (Stable Semantic Targets and Region Identity),
`v0.1.0` (Runtime Observation Foundation) - see `CHANGELOG.md`.
