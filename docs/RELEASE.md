# Release

`v0.4.0` is published to npm as `my-frontend-observer`, validated on
Windows, Linux, and macOS as an installed packed-tarball consumer prior to
publication (covering the legacy CSS-shorthand `--target` path, the
structured semantic `--targets-file` path, the bounded
`--scroll-scenario-file` `window-scroll-by`/`target-scroll-by` runtime
scroll scenario path, and the installed `compare` command's comparable and
incomparable cases). No project license has been declared yet; that
decision remains open for a later explicit task.

Observation, comparison, and package version remain separate: package
version is `0.4.0`; observation schema is `1.2.0` and comparison schema is
`1.0.0`, neither of which changes automatically with the package version.

Prior releases: `v0.3.0` (Runtime Scrolling, Overflow, and Visibility
Behavior), `v0.2.0` (Stable Semantic Targets and Region Identity), `v0.1.0`
(Runtime Observation Foundation) - see `CHANGELOG.md`.
