# Root Cause

The prior execution instructions incorrectly equated the orchestrator
greenfield `first-vertical-slice` stage with roadmap v0.1 / Project Milestone 1
implementation. That caused the greenfield scaffold and vertical-slice stages
to design and implement the actual browser-observation product before the user
authorized the required v0.1 planning workflow.

The correct project workflow is:

```text
greenfield foundation and forward-looking documents
→ completed bootstrap
→ read ROADMAP v0.1 and current repository state
→ perform retrieval/architecture work
→ design v0.1 steps and batches
→ only then implement v0.1
```

There is no Git repository at the project root, so no commit or preimplementation
tree was available as a restoration point. Provenance was reconstructed from
the scaffold implementation report, first-slice report, verification report,
final report, current filesystem, and the selected starter-profile contract.
