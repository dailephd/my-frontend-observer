## 4. Comparison against 8167ac5

The real workflow's independently-derived design (behavior-model.txt, pseudocode-packet.txt) matched the prior attempt's shape closely but not completely. Differences resolved on their own merits, not by default deference to either side:

- **Adopted from 8167ac5** (independently re-verified against this run's own retrieved evidence): reuse of the actual exported `schema.ts` runtime-value types (`TargetGeometry`, `TargetVisibility`, `OverflowEvidence`, `ScrollOwnerInterpretation`) rather than structurally duplicating them; and an explicit `sources: BoundedAgentContextSourceReferences` field referencing prior v0.1–v0.5 authoritative artifacts by id. Neither had been specified in this run's own behavior-model.txt/pseudocode-packet.txt — a real gap in this run's own design work, closed by independently checking it against `frontendContractEvaluationArtifact.ts`'s own source-reference-field convention (the strongest available precedent), not by copying the prior attempt uncritically.
- **Corrected relative to 8167ac5**: `StaticCandidateReference.evidenceRefs` and `RuntimeStaticCorrelationRecord.runtimeEvidenceRefs` were completely unbounded in the prior attempt, contradicting the request's own hard "no unbounded collection" constraint. This run adds `MAX_EVIDENCE_REFS_PER_CORRELATION_FIELD` and bounds both fields.
- **Corrected relative to this run's own pseudocode** (not an 8167ac5 difference): `buildBoundedAgentContextRequestIdentity`'s target-id array was pseudocoded as order-sensitive; a failing unit test (written from that same pseudocode) exposed this as an unverified assumption inconsistent with the repository's existing set-like-id-collection sorting convention. Reversed to order-insensitive, matching 8167ac5's own (independently correct) choice.
- **Added, not present in 8167ac5**: the `file:`/`symbol:` prefix-consistency check for `StaticCandidateReference.candidateId` (INV-009), which the prior attempt's validator never actually enforced despite describing the invariant in a doc comment.
